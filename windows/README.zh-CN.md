# Windows 本地改版 1.2.0

此版本以仓库 macOS 版为参照重做 Windows 面板。macOS 源码未修改。

## 使用

双击生成的 `QuotaMeter.exe`。单击系统托盘图标打开面板，点击面板外部或按 Esc 收起；后台继续按已保存的间隔刷新。

面板右上角依次是刷新、设置、退出。设置是独立窗口，填写 Base URL、接口类型、API Key，点击“保存并刷新”。完整的 Usage URL 也可填写。对于需要官网访问令牌的服务，网页登录后回到设置点击保存。

未编辑 API Key 时保留已保存的密钥；“清除密钥”会同时清除 API Key、Usage 令牌和面板中的旧数据。设置继续保存在 `%APPDATA%\QuotaMeter\settings.json`，密钥使用当前用户的 Windows DPAPI 加密。

## 对齐内容

- 紧凑的托盘弹出面板、圆角卡片、独立设置窗口。
- 主面板外框使用随 DPI 缩放的 24 像素圆角；背景采用中性深灰毛玻璃，统一去色和压暗，保留虚化的明暗层次，让白色文字清晰可读。
- 修复 Windows 10 原生 Acrylic 越过圆角、显示成矩形的问题。现在每次打开面板时读取窗口下方画面并虚化，打开期间背景固定，收起后释放，不保存到磁盘；再次打开会更新背景。
- 卡片增加轻阴影和细描边。高对比度模式或无法读取背景时使用实色背景。
- 标题、正文、说明和刷新状态固定使用白色，取消文字自动换色与局部衬底。顶部按钮使用深蓝底、白色加粗图标，并区分悬停和按下状态。
- 余额、币种、状态、套餐名；今日和累计用量、今日和累计请求。
- 限额进度、最近七天记录、累计输入/输出/缓存 Token 明细。
- 余额保留小数；Token 使用整数格式；本机余额差额记录明确标注“本机”。
- DPI 缩放适配，窗口空间不足时滚动显示。
- 兼容接口、OpenRouter、DeepSeek；保留已有密钥加密方式。

依赖服务商实际返回的数据，未返回的项目显示“—”。DeepSeek 只有 API Key 时显示余额并提示配置官网令牌；官网同步累计基于最近 30 天。用于预览截图的数据为示例。

## 修复

- 完整 Usage 地址被错误添加斜杠。
- 兼容接口的累计值先裁剪到七天再汇总。
- 定时刷新读取未保存的设置。
- 更换账号后旧请求的结果覆盖新账号数据。
- 网页登录只支持一个 localStorage 键名且无法处理纯文本令牌。
- 金额舍入为整数，造成小额余额看起来为零。

## 构建

安装 .NET 8 SDK，然后在仓库根目录运行：

```powershell
.\windows\build.ps1
```

生成 `windows-dist\QuotaMeter.exe`，包含 .NET 运行时。使用网页登录功能需要 Microsoft Edge WebView2 Runtime；缺失时窗口会提供提示。

## 验证

```powershell
dotnet run --project windows-tests/QuotaMeter.Tests.csproj -c Release
```

测试覆盖金额和 Token 格式、缓存与限额解析、超过七天的汇总、完整 Usage 地址与认证、无效密钥停止探测等。附加 `-- --render <目录>` 可生成实际 WinForms 截图，`-- --render-96 <目录>` 可检查 96 DPI。

本次已在 96 DPI 和本机 144 DPI 下检查面板及设置的滚动。未使用真实服务商密钥进行在线账户验证。
